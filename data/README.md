# Data — provenance

All public, downloaded pre-kickoff (allowed). Nothing here is generated by us.

## marson_perturbseq/  — the target dataset
Genome-scale CD4+ T-cell Perturb-seq (Zhu et al., Marson lab, bioRxiv Dec 2025).
Source: `s3://genome-scale-tcell-perturb-seq/marson2025_data/` (public, no-auth).
- `DE_stats.suppl_table.csv` — 33,983 perturbation×condition summary DE rows (THE core file, 4.6 MB)
- `sgrna_library_metadata.csv` — 26,504 guides → gene map
- `sample_metadata.csv` — 12 samples (4 donors × 3 conditions)
- `DATA_README.md` — the dataset's own schema doc (authoritative for column meanings)
Big `.h5ad`/`.h5mu` files (44–170 GB each) are NOT downloaded — not needed for v1.

## robustness/  — precomputed reproducibility metrics
From the analysis repo: github.com/emdann/GWT_perturbseq_analysis_2025 (`src/3_DE_analysis/results/`).
- `DE_donor_robustness_correlation_summary.csv` — per gene×condition cross-donor correlation
- `DE_by_guide_correlation_results.csv` — per gene×condition cross-guide correlation
These replace the 16.8 GB per-gene h5ad for the verifier's Tier-B robustness checks.

## external_screens/  — independent held-out validation
Two independent CD4+ T-cell CRISPR screens (from the same repo's `metadata/`), used to
corroborate picks the Marson screen flags (verifier Tier C3). MAGeCK output.
- `Schmidt2022_CRISPRi_gene_phenotypes.csv` — Schmidt & Steinhart 2022 (Science); readouts incl. CD4+ IL2, CD8+ IFNG
- `Freimer2022_Screen.csv` — Freimer 2022; readouts incl. IL2RA, CTLA4
