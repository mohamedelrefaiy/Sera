Stage 1 · analysis agent · rank

Score every knockout by how much it disturbs T‑cell activation

analysis agent

I’m starting from the full screen: 33,983 perturbation×condition rows. First I keep only perturbations with a real, significant on‑target knockdown — that’s 7,195 genes. Then I score each by the breadth of its downstream effect (how many genes move when you knock it out), weighted by knockdown strength, folded across the three conditions.

As a sanity check, the top of the raw list is the TCR signalosome — CD3E/D/G, LAT, ZAP70, VAV1. That’s exactly the known machinery of T‑cell activation. The data is behaving. But those aren’t drug targets — they’re the core wiring. The useful hits are hiding lower down.

methodscore = log1p(n_downstream) × |ontarget_effect_size|, gated on ontarget_significant, max across Rest/Stim8hr/Stim48hr

Stage 2 · analysis agent · actionability overlay

Rescue the druggable, disease-linked hits the raw ranking buries

analysis agent

Raw impact answers “what’s important to the cell,” not “what could we make a drug against.” So I overlay two independent axes from Open Targets: is the gene druggable (is there a small‑molecule or antibody handle?) and is it genetically linked to immune disease? Re‑ranking on the combination moves the list.

Watch what happens to three genes. The obvious signalosome member CD3E sinks — it’s essential but undruggable. Meanwhile PTPN2, buried at raw #812, rises to #45: a druggable phosphatase with type‑1‑diabetes genetics. This re‑ranking is the novel step.

Stage 3 · skeptic agent · adversarial verification

Try to break each candidate before trusting it

skeptic agent

My job is to refute, not confirm. For each candidate I run computed gates, no opinions: is the knockdown real and on‑target? Does the effect survive leaving each donor out? Does it hold across independent guide RNAs? A candidate that only works in one donor or one guide is an artifact, and I reject it.

Here’s the point of the whole tool — I kill things. A1BG looked ranked but fails the real-knockdown gate. DGKA has a strong knockdown but its downstream effect doesn’t reproduce across conditions, so it only gets a weak pass. That’s the difference between a shortlist and a wish list.

Stage 4 · skeptic agent · held-out confirmation

Confirm the top pick against evidence the pipeline never used

skeptic agent

Surviving my gates proves the effect is real in this screen. The stronger claim is that it’s real in the world. So I check each survivor against sources the ranking never saw as input: independent CRISPR screens (Schmidt 2022, Freimer 2022) and clinical trial status.

CBLB is a hit in two independent screens and has an inhibitor, NX‑1607, already in Phase 1. PTPN2 isn’t in those screens, but its drug ABBV‑CLS‑484 is in Phase 1 too — so it’s corroborated by the clinic, not the screen. I label each honestly.
