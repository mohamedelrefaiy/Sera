The ECC toolkit, and when to reach for each part.

Everything Claude Code is an MIT‑licensed harness that ships as a Claude Code plugin. It adds skills (workflow playbooks you invoke with /name), agents (specialists the main loop delegates to), and commands (slash shortcuts). This page is the map: what exists, and the one‑line cue for when it earns its keep.

How to use it

Three mechanics, three ways to invoke. You rarely install anything by hand — the plugin loads all of it, and the model pulls the right piece in on demand.

Skills · you invoke

Type a slash command

Skills are named playbooks. Trigger one explicitly by typing its name, or just describe the task — Claude auto‑loads a matching skill when the description fits.

/tdd-workflow   /deep-research
Agents · the loop delegates

Let it fan out to specialists

Agents are subagents with their own tools and system prompt. You don't call them directly — the main loop spawns code-reviewer, planner, etc. when the work fits, often several in parallel.

Commands · shortcuts

Run a packaged workflow

Commands are slash shortcuts that kick off a fixed sequence — build fixes, PR creation, reviews. Many are thin shims over the skill of the same name.

/pr   /code-review   /build-fix
